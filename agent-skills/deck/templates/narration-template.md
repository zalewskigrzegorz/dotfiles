# Czego NIE mówić

- **Żadnych imion** osób, o których mówisz krytycznie. Liczby robią robotę, nazwiska tworzą wrogów.
- Nie nazywaj cudzego narzędzia „zepsutym", jeśli część problemu to Wasze własne polityki.
- Nie podawaj liczb, których nie zmierzyłeś — ktoś powtórzy je jako fakt.
- Nie wchodź w wewnętrzności, o które nikt nie pytał.
